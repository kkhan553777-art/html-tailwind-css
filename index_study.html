HTML Study Notes: Beginner to Advanced

An elaborate educational explanation covering HTML from the ground up to advanced topics. No CSS concepts explained here. No JavaScript used.

1. Beginner Level

1.1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create web pages. HTML describes the structure of a page using elements, which are represented by tags. Tags tell the browser how to display content such as headings, paragraphs, images, links, lists, tables, and forms.

1.2 Basic HTML Document Structure

Every HTML page starts with a document type declaration, followed by the root element, then the head and body sections.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>This is my first web page.</p>
  </body>
</html>
  • <!DOCTYPE html> — Declares the document type and version (HTML5). It must be the very first line.
  • <html> — The root element that wraps all content on the page.
  • <head> — Contains metadata, the page title, character set, and links to resources. It is not visible on the page.
  • <body> — Contains all visible content that the user sees in the browser.

1.3 Headings and Paragraphs

HTML provides six levels of headings, <h1> through <h6>. <h1> is the most important (main page heading), and <h6> is the least important. The <p> tag defines a paragraph of text.

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<p>This is a paragraph of text. It explains something to the reader.</p>

1.4 Links

The <a> (anchor) tag creates hyperlinks. The destination is specified with the href attribute.

<a href="https://example.com">Visit Example</a>
  <a href="about.html">About Page</a>
<a href="#section2">Jump to Section 2</a>

1.5 Images

The <img> tag embeds an image. It is a self-closing (void) tag. The src attribute specifies the image file path, and the alt attribute provides alternative text for accessibility and when the image cannot load.

<img src="photo.jpg" alt="A description of the image" width="300" height="200" />

1.6 Lists

HTML supports unordered lists (<ul> with bullets), ordered lists (<ol> with numbers), and description lists (<dl> with terms and descriptions). Each item uses <li>.

<ul>
  <li>Apple</li>
  <li>Banana</li>
  <li>Cherry</li>
</ul>

<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>

1.7 Text Formatting

HTML offers tags to emphasize or mark up text inline.

  • <b> — Bold text
  • <strong> — Important/Bold text (semantic emphasis)
  • <i> — Italic text
  • <em> — Emphasized text (usually italic)
  • <u> — Underlined text
  • <mark> — Highlighted text
  • <small> — Smaller text
  • <del> — Deleted text (strikethrough)
  • <ins> — Inserted text (underlined)
  • <sub> — Subscript
  • <sup> — Superscript

2. Intermediate Level

2.1 Semantic HTML Tags

Semantic tags clearly describe their meaning to both the browser and the developer. Using semantic tags improves accessibility, SEO, and code readability.

TagPurpose
<header>Introductory content or navigation links, usually at the top of a page or section.
<nav>Major navigation block, such as menus.
<main>The dominant content of the <body>. There should be only one <main> per page (excluding hidden ones).
<section>A thematic grouping of content, typically with a heading.
<article>Independent, self-contained content like a blog post or news item.
<aside>Content tangentially related to the main content, such as sidebars.
<footer>Footer for a page or section, often containing copyright and contact info.
<figure>Self-contained content like an image, diagram, or code snippet.
<figcaption>A caption or description for the parent <figure>.
<details> and <summary>A disclosure widget that the user can expand or collapse.
<mark>Highlighted or marked text.
<time>A specific time or date, machine-readable via the datetime attribute.

2.2 The <main> Tag

The <main> element represents the primary content of a document. It should contain content that is unique to that page and not repeated across pages (such as navigation, logos, or footers). A page should normally have only one <main> element that is not hidden.

<body>
  <header>...site header...</header>
  <nav>...navigation...</nav>
  <main>
    <h1>Page Topic</h1>
    <p>The unique, primary content goes here.</p>
  </main>
  <footer>...site footer...</footer>
</body>

2.3 Tables

HTML tables organize data into rows and columns. <table> is the container, <tr> defines a row, <th> defines a header cell, and <td> defines a data cell.

<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Role</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alice</td>
      <td>Developer</td>
    </tr>
    <tr>
      <td>Bob</td>
      <td>Designer</td>
    </tr>
  </tbody>
</table>

2.4 HTML Entities

Some characters have special meaning in HTML (such as < and >) and must be written as entities so they display as text instead of being interpreted as tags.

  • &lt; — less than (<)
  • &gt; — greater than (>)
  • &amp; — ampersand (&)
  • &quot; — double quote (")
  • &apos; — apostrophe (')
  • &nbsp; — non-breaking space
  • &copy; — copyright symbol (©)

2.5 SVG (Scalable Vector Graphics)

SVG lets you draw vector graphics directly inside HTML using XML-based markup. Because it is vector-based, it scales without losing quality. You embed SVG with the <svg> container and draw shapes inside it.

<svg width="200" height="100" xmlns="http://www.w3.org/2000/svg">
  <rect x="10" y="10" width="180" height="80" fill="blue" />
  <circle cx="100" cy="50" r="40" fill="red" />
  <text x="100" y="70" text-anchor="middle" fill="white">SVG Example</text>
</svg>

Common SVG elements include <rect> (rectangle), <circle>, <ellipse>, <line>, <polygon>, <path>, and <text>.

2.6 Audio and Video

HTML5 provides native tags to embed multimedia without plugins.

<audio controls>
  <source src="song.mp3" type="audio/mpeg" />
  Your browser does not support the audio element.
</audio>

<video width="320" height="240" controls poster="thumbnail.jpg">
  <source src="movie.mp4" type="video/mp4" />
  Your browser does not support the video element.
</video>
  • controls — shows play, pause, and volume controls.
  • src or nested <source> — specifies the media file.
  • type — tells the browser the MIME type of the media.
  • poster — image shown while the video is downloading.
  • autoplay — starts playing automatically.
  • loop — repeats the media.
  • muted — starts with sound off.

2.7 Iframes

The <iframe> tag embeds another HTML page within the current page.

<iframe src="https://example.com" width="600" height="400" title="Embedded page"></iframe>

2.8 Meta Tags

Meta tags live in the <head> and provide metadata about the HTML document.

<meta charset="UTF-8" />
<meta name="description" content="A study page about HTML" />
<meta name="author" content="Student" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
  • charset — defines the character encoding (UTF-8 is standard).
  • viewport — controls layout on mobile browsers.
  • description — used by search engines.

3. Advanced Level

3.1 HTML Forms

Forms collect user input. The <form> element wraps controls such as text fields, checkboxes, radio buttons, select menus, and buttons. The action attribute tells the form where to send data, and method defines how (usually GET or POST).

<form action="/submit" method="post">
  <label for="name">Full Name:</label>
  <input type="text" id="name" name="name" required />

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required />

  <label>
    <input type="checkbox" name="terms" /> I accept the terms
  </label>

  <fieldset>
    <legend>Choose an option</legend>
    <label>
      <input type="radio" name="choice" value="a" /> Option A
    <label>
    <label>
      <input type="radio" name="choice" value="b" /> Option B
    </label>
  </fieldset>

  <label for="color">Favorite Color:</label>
  <input type="color" id="color" name="color" />

  <label for="rating">Rating (1-5):</label>
  <input type="number" id="rating" name="rating" min="1" max="5" />

  <button type="submit">Submit</button>
  <button type="reset">Reset</button>

3.4 Select Menus and Textareas

    
<select> creates a dropdown list, and <textarea> creates a multi-line text area.

    
<label for="country">Country:</label>
<select id="country" name="country">
  <option value="us">United States</option>
  <option value="in">India</option>
  <option value="uk">United Kingdom</option>
</select>

<label for="bio">Biography:</label>
<textarea id="bio" name="bio" rows="4" cols="50">Write something about yourself...</textarea>


    
3.5 Datalist and Output

    
<datalist> provides autocomplete suggestions for an input. <output> displays the result of a calculation or user action.

    
<input list="browsers" name="browser" />
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
</datalist>

<output id="result" name="result">0</output>


    
3.6 Fieldset and Legend

    
<fieldset> groups related controls together, and <legend> provides a caption for that group.

    
<fieldset>
  <legend>Account Information</legend>
  <label for="username">Username:</label>
  <input type="text" id="username" name="username" />
</fieldset>


    
3.7 Scripting and Noscript

    
<script> embeds or references JavaScript. <noscript> displays fallback content if scripts are disabled or unsupported.

    
<script src="app.js"></script>
<noscript>Please enable JavaScript to view this page correctly.</noscript>


    
3.8 HTML Best Practices

    
    
      
  • Always declare <!DOCTYPE html> as the first line.
    • 
      
  • Use semantic tags (<header>, <main>, <footer>, etc.) instead of only <div> and <span>.
    • 
      
  • Provide meaningful alt text on every image.
    • 
      
  • Associate every input with a <label> using matching for and id attributes.
    • 
      
  • Use lang on the <html> tag to declare the page language.
    • 
      
  • Keep tags properly nested and closed.
    • 
      
  • Use heading levels in order (<h1> then <h2> then <h3>) without skipping levels.
