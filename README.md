# HTML Tailwind CSS Practice

This repository contains HTML practice files used for learning semantic page layout, CSS fundamentals, and web development structure.

## Repository Purpose

Practice and study HTML semantic tags and internal CSS styling. These files are preserved exactly as written — no modifications have been made to the original source code.

## Files Included

| File | Description |
|------|-------------|
| `index_css_notes.html` | CSS notes and reference |
| `index_practice_study.html` | HTML practice study |
| `index_practice_study2.html` | HTML practice study 2 — semantic tags for page layout |
| `index_study.html` | HTML study file |

## File Excluded

- `index_qrp.html` — Excluded from this repository.

## How to Use

1. Clone this repository.
2. Open any `.html` file in your web browser to view it.
3. Edit files locally to continue practicing HTML and CSS.

## Notes

- No external CSS frameworks (such as Tailwind) are currently included.
- All styling is internal (inside `<style>` tags in the `<head>`).
- HTML files are unchanged from their originals.
